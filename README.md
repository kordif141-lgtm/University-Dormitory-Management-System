# سامانه مدیریت خوابگاه

## ۱. معرفی پروژه

سامانه مدیریت خوابگاه یک سیستم برای مدیریت بهتر امور خوابگاه، سازمان‌دهی اتاق‌ها، ارائه خدمات به دانشجویان و اطلاع‌رسانی اخبار و اعلامیه‌ها است.

## ۲. هدف پروژه

هدف این پروژه، ساده‌تر کردن مدیریت خوابگاه و ایجاد دسترسی آسان دانشجویان به اطلاعات اتاق‌ها، خدمات و اطلاعیه‌های مهم است.

## ۳. ویژگی‌های اصلی سامانه

* اتاق‌بندی: ثبت اطلاعات اتاق‌ها، مشخص کردن ظرفیت هر اتاق و مدیریت وضعیت اسکان دانشجویان
* مدیریت خدمات: ثبت و نمایش خدمات خوابگاه مانند نظافت، تعمیرات و امکانات رفاهی
* اعلامیه‌ها: انتشار اطلاعیه‌های مهم درباره قوانین خوابگاه، برنامه‌ها و زمان‌بندی خدمات
* مدیریت اطلاعات دانشجویان: ثبت اطلاعات دانشجویان ساکن در خوابگاه
* مشاهده اطلاعات اتاق‌ها: امکان مشاهده شماره اتاق، ظرفیت و وضعیت خالی یا تکمیل بودن آن
* درخواست خدمات: امکان ثبت درخواست برای تعمیرات یا دریافت خدمات موردنیاز
* اطلاع‌رسانی: نمایش اخبار و اطلاعیه‌های جدید به دانشجویان

## ۴. کاربران سامانه

* مدیر خوابگاه
* مسئولان خوابگاه
* دانشجویان ساکن در خوابگاه
